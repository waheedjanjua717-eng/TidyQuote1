# TidyQuote – Cleaning Business Quoting Software

[Visit TidyQuote](https://tidyquote.site)

TidyQuote helps independent house cleaners create professional cleaning quotes, manage clients, and follow up with potential customers.

## Features
- Professional cleaning quote generator
- Client management
- Custom cleaning services and extras
- Quote acceptance and rejection
- Automatic follow-up reminders
- Quote search and export

## Who Is It For?
Independent house cleaners and small cleaning businesses.
